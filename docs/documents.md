# DOCX와 PPTX 윤문

0.3.0부터 웹 포털, Windows 앱, Claude·Codex `humanize-kr` 스킬에서 DOCX·PPTX를 처리합니다. 파일 읽기·저장에 Office 설치는 필요하지 않습니다. Windows 배포물은 Python과 lxml 6.1.3을 포함합니다.

## 사용

웹/앱에서 파일 불러오기를 눌러 DOCX 또는 PPTX를 선택합니다. 문서 위치별 텍스트 미리보기와 윤문/보존 구간을 확인하고 Claude 또는 Codex를 선택해 변환합니다. 완료 후 결과 저장을 누르면 입력과 같은 확장자의 새 파일을 받을 수 있습니다. 미리보기는 실제 페이지·슬라이드 렌더링이 아닙니다.

스킬에서는 `/humanize-kr` 또는 `$humanize-kr`에 파일 경로를 전달합니다. 현재 호스트 모델이 편집하고 Gateway가 서식·내용을 검증합니다. 원본을 덮어쓰지 않으며 기존 결과가 있으면 다른 이름을 사용합니다.

## 보존 범위

본문, 표 셀, 지원되는 텍스트 상자·도형의 한국어 텍스트를 대상으로 합니다. 문단·셀·슬라이드·도형 ID, 글꼴·강조·색상 등 서식, 그림·테마·미디어·관계 파일은 유지합니다. 줄바꿈·탭을 보호하면서 그 사이의 텍스트는 편집할 수 있습니다.

머리글·바닥글·각주·미주·발표자 노트·마스터·차트·SmartArt·수식은 그대로 보존합니다. 하이퍼링크, 필드, 변경 추적, 콘텐츠 컨트롤, 처리하기 어려운 호환 객체는 보호합니다. 일부 객체의 텍스트를 윤문하지 않을 수 있으며 위치별 경고로 알립니다.

숫자·영문 이름 등이 있는 문장은 보수적으로 보호하고 직접 인용도 보호합니다. 서식 경계를 넘거나 부정·당위·추측을 바꾸는 편집, 문단 변경률 50% 이상, PPTX 텍스트 길이 증가는 재시도하며 해결되지 않으면 원문을 유지합니다. 이러한 검사는 일반적인 의미 동치 전체의 증명은 아닙니다.

PPTX는 원문보다 길어지지 않게 처리하지만 글자 폭·폰트 차이로 배치가 달라질 수 있으므로 최종 슬라이드를 확인해 주세요. DOCX는 윤문 후 자연스럽게 페이지 나눔이 바뀔 수 있습니다.

## 크기와 파일 제한

- 압축 파일 50 MiB, 해제 합계 250 MiB, XML part 10 MiB, 내부 파일 10,000개
- 전체 추출 텍스트 100,000자, PPTX 200슬라이드
- 개별 9,000자 초과 문단은 현재 원문을 보존하고 경고합니다. 긴 문서는 여러 문단으로 구성하면 배치 처리할 수 있습니다.
- DOC/PPT/PDF/HWP, 매크로·서명·암호화·편집 보호 파일은 지원하지 않습니다.

## 임시 파일 수명

웹의 업로드/결과는 작업별 권한 토큰으로 보호합니다. 비활성 문서는 마지막 사용 후 30분에 정리하며 초기화·취소·실패 시 해당 임시 문서를 정리합니다. 다운로드가 끝난 결과는 만료 전까지 다시 받을 수 있습니다. 서버 재시작 시 임시 문서 작업을 재개하지 않습니다.

앱은 저장 취소 후에도 결과를 다시 저장할 수 있습니다. 새 파일 선택·초기화·앱 종료·만료 시 임시 파일을 정리합니다. 스킬은 결과를 사용자가 선택한 경로에 저장한 후 Gateway cleanup을 실행합니다. 사용자 원본과 내보낸 결과는 삭제하지 않습니다.

## 개발과 검증

`npm run desktop:build`가 고정한 lxml Windows wheel을 SHA-256으로 확인해 내장 Python에 배치합니다. 그 후 `npm run test:documents`로 문서 보존 검사를 실행합니다. 웹 개발에서도 Windows에서는 준비된 내장 Python을 우선 사용합니다. 다른 OS에서는 Python 3.11+에 `pip install lxml==6.1.3`으로 동일 버전을 준비합니다.

- `tests/documents/test_documents.py`: 구조·서식·보호 범위·XML·ZIP·Gateway 검증
- `tests/integration/documents.test.ts`: 실제 Python + 모의 CLI의 웹 왕복/권한 검사
- `tests/desktop/app.spec.ts`: 앱에서 DOCX/PPTX 열기·저장
- `scripts/verify-skill-packages.mjs`: 설치된 두 스킬에서 내장 Python으로 TXT/DOCX/PPTX 왕복
- `scripts/smoke-documents.mjs`: 실제 로그인된 두 CLI를 사용한 DOCX/PPTX 검사

모델은 문서의 XML이나 바이너리를 직접 편집하지 않습니다. source hash·블록 ID·Unicode code point 범위로 편집을 제안하고, 공통 Python 어댑터가 검증된 텍스트만 원본 패키지에 반영합니다. 검증되지 않은 파일은 내보내지 않습니다.
