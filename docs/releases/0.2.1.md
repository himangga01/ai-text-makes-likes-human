## 반영 내용

- A-16 대명사 처리를 빈도·삭제 비율 기준에서 문맥의 선행 명사구 기준으로 변경.
- A-22 평가 술어, A-24 ‘더 이상’ 표현 규칙을 quick-rules에 반영.
- 진단 카탈로그에 A-23 기반 마련 표현 등 새 항목 반영.
- C-8 표현을 윤문 과정에서 새로 주입하지 않도록 관련 지침 보강.
- quick 규칙 61개, 진단 패턴 84개로 갱신.
- 포털의 줄바꿈·분할·서법 복원·쉼표 처리 패치는 수정 없이 재적용.
- `sync-engine.ps1`은 `-Source`를 필수로 받고, 소스의 미커밋 변경·필수 파일 누락을 복사 전에 거부하도록 보완.
- 출처 기록을 사용자 포크 URL로 일치시킴.

## 스킬 동작 변경

`update-humanize-engine` 실행 범위에 원본 조회, 포크 동기화·push, 서비스 반영·검증, EXE·스킬 재빌드를 포함했다. 원본과 포크 HEAD가 같으면 불필요한 clone·push를 생략한다. 포크 고유 변경이 있으면 보존하는 merge를 수행하고 force-push는 사용하지 않는다.

해시 차이를 새 버전으로 오판하지 않도록 ancestry 검사는 유지한다. 실제 후손만 업데이트로 보고하며, 오래된 포크는 먼저 원본과 동기화한다. 점검만 요청한 경우에는 쓰기를 하지 않는다. 저장소와 개인 설치본을 함께 갱신했다.

- 감지 회귀 테스트 12개 및 스킬 형식 검사 통과.
- 서버·Electron TypeScript 검사, 규칙 인덱스 검사 통과.
- 일반 단위·통합 188개, 웹·시각·접근성 17개, 패키징된 데스크톱 7개, Gateway 3개: **총 215개 통과**.
- 두 스킬 ZIP의 설치·반복 설치·내장 Python Unicode roundtrip·cleanup 통과.
- 새 portable EXE를 복사한 경로에서 실제 Codex·Claude CLI로 각각 변환·수치 보존·cleanup 확인.
- 동일 upstream 핀으로 재동기화한 vendor가 바이트 단위로 동일함을 확인.
- 실제 LLM 확인은 짧은 문서 smoke test이며, 12회 성능 벤치마크는 실행하지 않음.

Windows 11 Pro x64에서 검증했다. 기존 0.2.0 일반 EXE와 자체서명 EXE는 보존했다. 설치된 Claude·Codex 윤문 스킬도 기존 설치를 백업한 뒤 0.2.1로 갱신했다.
