# 0.5.0 — 다섯째 강도, 파일 강도, 슈퍼세종엔진, MCP 서버

0.4.0(2026-09-10) 이후의 변경을 묶은 버전이다. 같은 0.4.0 이름으로 다른 코드가 배포되지 않도록 버전을 올렸다.

## 윤문

- **다섯째 강도 '매우 강하게(다시쓰기)'(`rewrite`)를 추가했다.** 기본 엔진에서는 매우 강하게와 같이 처리한다. 슈퍼세종엔진 v2에서는 문단마다 크게 다시 쓰되 숫자·인용·이름·뜻·행동 요청은 그대로 둔다.
- **TXT·MD 파일도 강도를 고를 수 있다.** 같은 강도의 직접 입력과 같은 편집 범위·보호 규칙을 쓴다. 결과에는 사용한 강도를 표시한다. 변경 비교 표시는 직접 입력에만 있다. DOCX·PPTX는 서식을 지키기 위해 보통으로 처리한다.
- **보존 검사 오탐을 고쳤다.** 기존 엔진과 v2 모두, 정상 수정을 원문으로 되돌리던 경우가 줄었다.
- **입력 한도를 정했다.** 직접 입력과 TXT·MD는 100,000자까지 받는다. TXT·MD 파일은 1 MiB를 넘으면 읽기 전에 거절한다.

## 슈퍼세종엔진

- **이 프로젝트가 직접 만든 윤문 엔진 v2가 함께 들어간다.** 고칠 문장만 골라 요청하고, 돌아온 결과를 문장마다 검사한다(원래 말투, 뜻, 숫자·인용 보존). 걸린 문장은 그 문장만 되돌린다.
- **기본 엔진은 여전히 기존 엔진이다.** `SUPER_SEJONG_ENGINE=v2`로 켠다. 운영 서버는 v2를 기록 모드(`SUPER_SEJONG_V2_SHADOW=1`)로 돌려 비교 자료를 모은다.

## 모델

- **기본 모델을 바꿨다.** GPT-6.1 Sol(`gpt-6.1-sol`, high), Claude Opus 5.5(`claude-opus-5-5`, xhigh).
- **추가:** GPT-6.1 Sol, Claude Opus 5.5·Sonnet 5.5·Haiku 5.5.
- **목록에서 제외:** GPT-5.2(ChatGPT 계정 Codex에서 지원 종료), GPT-5.5(2026-10-14 지원 종료 예정).

## 스킬

- **Claude·Codex용 `humanize-kr` 스킬도 위 변경을 따른다.** 직접 입력 강도는 5단계이고, TXT·MD 파일 강도(`--input-kind text-file --strength <강도>`)를 지원하며, 슈퍼세종엔진 v2를 포함한다.
- **0.4.0 스킬은 TXT·MD 강도 요청을 거절한다.** 0.5.0 ZIP으로 다시 설치해야 한다.

## MCP 서버

- **Claude Code·Codex 같은 MCP 클라이언트가 포털을 도구로 부를 수 있다.**
  - `humanize_text`: 글 윤문.
  - `humanize_file`: TXT·MD·DOCX·PPTX 파일을 다듬어 새 파일로 저장한다.
  - `humanize_status`: 포털 상태.
- **포털 작업 그대로 처리한다.** 호출 하나가 포털 작업 하나라서 웹 화면과 같은 대기열·모델·보존 검사를 거친다.
- **새 의존성이 없다.** 등록과 사용법은 README의 "MCP 서버로 쓰기"와 [MCP Server Guide](../mcp.md)에 있다.

## 배포

Windows PC에서 빌드한다(아직 만들지 않음).

- `release/HumanizeKR-0.5.0-win-x64-self-signed.exe`
- `release/humanize-kr-claude-0.5.0-win-x64.zip`
- `release/humanize-kr-codex-0.5.0-win-x64.zip`

기존 스킬은 사용자별 `skill-backups`에 보존한 뒤 갱신한다. Windows x64 배포물이며, 자체서명은 공개 신뢰 인증서가 아니다.
