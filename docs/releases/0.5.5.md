# 0.5.5 — 윤문 엔진 2.4.8

0.5.4 이후의 변경이다.

## 윤문 엔진

- **기존 엔진을 2.4.7에서 2.4.8로 올렸다.** 원본은 `epoko77-ai/im-not-ai`의 커밋 `e9793d7`이다. 이전 핀 `c07df14` 이후 6개 커밋이다.
- 실행 스크립트는 바뀌지 않았다. 규칙 문서 세 개만 바뀌었다. 그중 `quick-rules.md`는 윤문 요청에 그대로 들어간다.
  - **F-5 ("~적 N" 연쇄):** '-적'만 떼는 것은 굳은 두 낱말 합성어일 때만 허용한다("학술적 연구" → "학술 연구"). 떼고 나서 명사가 조사 없이 셋 이상 이어지면 금지한다("AI 전략 함의 분석"). 그 밖에는 "실천적 기반" → "실천의 기반"처럼 풀어 쓴다.
  - **E-5 (긴 절):** 8어절 이상 절은 마침표로 나눈다. 관형절로 압축하지 않는다. 압축하면 명사 앞 수식이 길어져 다른 AI 티(A-18)를 새로 만든다.
  - **C-8 (대구 해체):** 끊어서 풀 때도 대조·인과를 잇던 표지("그런데"·"그래서" 등)는 하나 남긴다.
- 포털 패치는 그대로 적용된다. 어휘 점검·어휘 복원·명사 예외는 바뀌지 않았다.
- 서버 준비 검사가 엔진 라벨 2.4.8을 요구한다. vendor 파일과 `npm run build` 결과를 함께 반영하고 재시작한다.
- 엔진이 바뀌기 전에 시작한 스킬 작업은 다음 단계에서 거절된다. 새 작업으로 다시 시작한다.
