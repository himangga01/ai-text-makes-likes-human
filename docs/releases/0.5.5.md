# 0.5.5 — 윤문 엔진 2.4.8, MCP 연결 안내

0.5.4 이후의 변경이다.

## 윤문 엔진

- **기존 엔진을 2.4.7에서 2.4.8로 올렸다.** 원본은 `epoko77-ai/im-not-ai`의 커밋 `e9793d7`이다. 이전 핀 `c07df14` 이후 6개 커밋이다.
- 실행 스크립트는 바뀌지 않았다. 규칙 문서 세 개만 바뀌었다. 그중 `quick-rules.md`는 윤문 요청에 그대로 들어간다.
  - **F-5 ("~적 N" 연쇄):** '-적'만 떼는 것은 굳은 두 낱말 합성어일 때만 허용한다("학술적 연구" → "학술 연구"). 떼고 나서 명사가 조사 없이 셋 이상 이어지면 금지한다("AI 전략 함의 분석"). 그 밖에는 "실천적 기반" → "실천의 기반"처럼 풀어 쓴다.
  - **E-5 (긴 절):** 8어절 이상 절은 마침표로 나눈다. 관형절로 압축하지 않는다. 압축하면 명사 앞 수식이 길어져 다른 AI 티(A-18)를 새로 만든다.
  - **C-8 (대구 해체):** 끊어서 풀 때도 대조·인과를 잇던 표지("그런데"·"그래서" 등)는 하나 남긴다.
- 포털 패치는 그대로 적용된다. 어휘 점검·어휘 복원·명사 예외는 바뀌지 않았다.
- 서버 준비 검사가 엔진 라벨 2.4.8을 요구한다. vendor 파일과 `npm run build` 결과를 함께 반영하고 재시작한다.
- 엔진이 바뀌기 전에 시작한 스킬 작업은 다음 단계에서 거절된다. 새 작업으로 다시 시작한다.

## 웹 포털

- **페이지 맨 아래에 접힌 "MCP 연결 방법" 안내를 넣었다.** 누르면 펼쳐지고, 키보드(Enter·Space)로도 연다.
  - 맨 앞에 "이 포털을 실행하는 PC에서 연결합니다"를 둔다. MCP 서버는 같은 PC의 포털(`127.0.0.1:7882`)에만 연결되고, 외부 주소로는 연결되지 않는다(외부 주소는 브라우저 로그인이 필요하다).
  - 빌드, Claude Code·Codex 등록(Mac·Windows), Codex `tool_timeout_sec = 3600`, Claude Code `MCP_TOOL_TIMEOUT`, 연결 확인 명령, 도구 세 개, 자주 나는 문제를 담았다. 명령마다 복사 버튼이 있다.
  - 경로는 `<저장소 경로>` 같은 자리 표시로만 적고, 개인 경로나 외부 주소 이름은 넣지 않았다.
  - 포털 서버가 없는 데스크톱 앱에서는 숨긴다.
- Windows 화면 비교 테스트(`tests/e2e/portal-visual.spec.ts`)의 기준 이미지는 페이지가 길어져 다시 만들어야 한다. Windows PC에서 `npx playwright test tests/e2e/portal-visual.spec.ts --update-snapshots`를 실행하고, 차이가 이 안내 한 줄뿐인지 확인한다.
