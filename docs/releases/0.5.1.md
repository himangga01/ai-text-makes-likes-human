# 0.5.1 — 모델 목록을 CLI에서 실시간으로 받기

0.5.0 이후의 변경이다.

## 모델

- **모델 목록을 CLI에서 직접 받는다.** 서버가 켜질 때 한 번 받고, 그 뒤에는 목록을 받은 지 10분이 지났거나 CLI 버전이 바뀌었을 때 다시 받는다.
  - Codex에는 `codex app-server`의 `model/list`로 묻는다.
  - Claude Code에는 초기화 응답의 모델 목록을 읽는다.
  - 둘 다 프롬프트를 보내지 않으므로 사용량이 들지 않는다.
- **CLI에 새 모델이 생기면 연결 설정에 바로 나타난다.** 웹·데스크톱 앱은 새로 고치지 않아도 목록이 바뀐다.
- **목록에 없는 모델로 요청하면 그 자리에서 목록을 한 번 더 확인한다.** 엔진별로 30초에 한 번까지다. 그래도 없으면 예전처럼 `INVALID_MODEL_SETTINGS`로 거절한다.
- **CLI에 물을 수 없으면 직전 목록을 계속 쓴다.** 한 번도 받지 못했으면 기본 목록을 쓰고, 1분 뒤 다시 시도한다.
- **`/api/health`에 `modelCatalog`가 추가됐다.** 엔진별로 목록을 어디서 받았는지(`live`: CLI, `fallback`: 기본 목록), 확인 시각, CLI 버전, 마지막 오류 코드가 담긴다.
- **기본 목록에 새 모델을 넣었다.** 2026-11-13 기준이다.
  - GPT: GPT-6.1 Terra
  - Claude: Fable 5.2, Fable 5, Opus 4.8, Opus 4.7, Opus 4.6, Sonnet 4.6
- **목록에 넣지 않는 모델이 있다.** CLI가 숨긴 모델, 그리고 추론 수준을 고를 수 없는 모델(Claude Haiku 4.5)이다.
- **기본값은 GPT-6.1 Sol(high), Claude Opus 5.5(xhigh) 그대로다.** CLI 목록에서 기본 모델이 빠지면 CLI가 정한 기본 모델로 바꿔 제공한다.

## 데스크톱 앱

- **저장해 둔 모델 선택을 앱을 다시 켤 때 버리지 않는다.** CLI에서 받은 새 모델을 골라 두었을 때를 위한 변경이다. 실제로 쓸 수 있는지는 연결 상태를 확인할 때 다시 맞춘다.

## MCP 서버

- **`humanize_status`가 CLI에서 받아 온 모델 목록을 돌려준다.** 도구 이름과 인자는 그대로다.
