# 0.5.2 — GPT 기본 모델을 GPT-6.2 Sol로

0.5.1 이후의 변경이다.

## 모델

- **GPT 기본 모델을 GPT-6.2 Sol(`gpt-6.2-sol`)로 바꿨다.** 추론 수준은 예전처럼 `high`다.
  - OpenAI 모델 문서가 GPT-6.2 Sol을 일상 작업용 추천 모델로 소개한다.
  - 모델을 직접 고른 적이 없는 웹·앱 사용자는 새 기본값을 따른다. 직접 골라 저장한 선택은 그대로 둔다.
- **기본 목록에 GPT-6.2 Sol과 GPT-6.2 Astra를 넣었다.** 두 모델 모두 `low`~`ultra`를 지원한다.
  - 2026-11-19에 Codex CLI 0.170.0이 알려 준 목록과 순서를 그대로 따른다.
  - 기본 목록은 CLI에 물을 수 없을 때만 쓴다. CLI에 물을 수 있으면 0.5.1처럼 CLI 목록을 쓴다.
- **Claude는 바뀌지 않았다.** Claude Code 2.1.328 목록이 기존 기본 목록과 같고, 기본값도 Claude Opus 5.5(`xhigh`) 그대로다.

## 그 밖

- 스킬은 호스트 세션의 모델을 쓰므로 바뀌지 않는다. MCP 서버는 포털 기본값을 따르므로 코드 변경이 없다.
