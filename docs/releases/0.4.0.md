# 0.4.0 — 직접 입력 강도와 변경 비교

- 웹·Windows 앱의 직접 입력에 보통·중간·강하게·매우 강하게와 각 단계 설명을 추가했다. 실행 당시 강도를 결과에 표시하고 선택값을 저장한다.
- 최종 검증된 결과를 원문과 비교해 추가·변경은 연노랑, 삭제는 빨강 취소선으로 표시한다. 최종문 보기와 복사·저장은 순수 결과만 제공한다. 입력·결과 필드의 높이와 시작 위치를 맞췄다.
- 문장 구조·인식된 핵심어·보호 문장을 검사하고 불확실한 편집은 재시도하거나 원문을 유지한다. 매우 강하게의 문체 통계 경고만 발생한 경우에는 실제 두 번째 호출이 보호 검사를 통과한 초안을 원문과 대조한다. 문자 변경률 30/50 기준과 최대 한 번의 재시도는 유지한다.
- Claude·Codex용 `humanize-kr` 스킬에 직접 입력 강도와 독립 HTML 변경 비교를 추가했다. Windows ZIP에 Python·Node와 공통 검증 코드를 포함한다. 현재 호스트가 윤문하며 다른 모델 CLI나 웹 서비스를 중첩 실행하지 않는다.
- TXT·MD·DOCX·PPTX 파일 입력은 기존 흐름을 유지한다.

## 검증 범위

구현 과정에서 Vitest 311개, 웹 32개, Electron 10개, 문서 28개와 타입 검사가 통과했다. 이후 UI 수정은 관련 테스트와 화면 비교로 확인했다. 스킬 구현은 Python 17개, 브라우저 HTML 비교 5개 및 두 호스트의 격리 패키지 검증을 완료했다. 숫자는 각 단계의 실행 기록이며 같은 시점의 단일 전체 실행 합계가 아니다.

사용자가 추가 측정과 확인을 중단하도록 요청했다. 이에 따라 마지막 스킬 코드 리뷰, 전체 브랜치 최종 리뷰, 신규 EXE 실행 검증과 설치된 호스트의 추가 사용 검증은 수행하지 않았다. 최종 실제 모델의 변경량·속도도 재측정하지 않았다. [실측 기준선과 종료 범위](../research/2026-09-10-strength-live-evaluation.md), [구현 중 결정](../research/2026-09-10-implementation-decisions.md)을 참고한다.

## 배포

- `release/HumanizeKR-0.4.0-win-x64-self-signed.exe`
- `release/humanize-kr-claude-0.4.0-win-x64.zip`
- `release/humanize-kr-codex-0.4.0-win-x64.zip`

기존 스킬은 사용자별 `skill-backups`에 보존한 뒤 갱신한다. Windows x64 배포물이며 자체서명은 공개 신뢰 인증서가 아니다. 다른 OS에서는 Windows ZIP 대신 소스 구성과 해당 OS의 Python·Node를 사용해야 한다.

이번 EXE는 빌드 임시 디렉터리 잠금을 피하기 위해 같은 버전의 설치된 Electron 44.2.0 배포 디렉터리를 사용해 패키징했다.
