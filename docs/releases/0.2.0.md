# v0.2.0 — Windows portable 앱과 Claude·Codex 윤문 스킬

검증일: 2026-09-07. OS: Windows 11 Pro x64, 10.0.26200.

## 제공 내용

- PC에 설치·로그인된 Claude Code 또는 Codex CLI를 선택하는 Electron Windows 앱.
- Electron 44.2.0, Python 3.14.7을 포함한 단일 portable EXE.
- 호스트 세션에서 윤문하고 공유 Python Gateway로 검증하는 `humanize-kr` 스킬 두 배포물과 설치 도우미.
- CLI별 설치·로그인 점검, 원문 수치·인용의 보존 실패 차단, 원문 복원·검토 경고 유지.
- 기존 LAN 포털과 동일한 엔진·규칙을 사용하며 데스크톱은 HTTP 서버 없이 IPC로 실행.

## 검증 범위와 운영 조건

- 실제 모델 호출은 앱의 CLI runner 경로에서 각 엔진의 짧은 문서로 확인했다. 스킬 패키지는 Gateway와 배포·설치를 검증했으며, 각 호스트의 대화 UI에서 장문을 끝까지 생성하는 모델 평가는 별도다.
- 같은 PC에서 복사 경로와 PATH를 격리해 실행했다. 별도 Windows 10 기기나 신규 Windows 설치 VM 검증은 수행하지 않았다.
- 코드 서명은 적용하지 않았고 Authenticode 상태는 `NotSigned`다.
- 12회 성능 벤치마크는 실행하지 않았다. 짧은 smoke test를 장문 품질·처리 시간 보장으로 해석하지 않는다.
- CLI 설치·로그인·인터넷 연결은 사용자 환경을 이용한다. 앱이 CLI를 설치·로그인하거나 다른 엔진으로 자동 전환하지 않는다.

실행·설치·재빌드 방법은 [Windows 앱 안내](../desktop.md)에 있다.
