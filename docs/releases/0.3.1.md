# HumanizeKR 0.3.1

웹과 Windows 앱에서 CLI 연결 상태, 모델·추론 레벨, 작업 경과 시간을 확인할 수 있습니다.

- Codex/Claude별 모델·추론 레벨 선택 메뉴를 추가했습니다. 지원되는 조합만 선택할 수 있으며 실제 TXT/MD/DOCX/PPTX 작업과 재시도에 전달합니다.
- 웹 설정은 해당 브라우저에, Windows 앱 설정은 앱의 사용자 설정에 저장합니다. CLI 자체의 전역 설정은 변경하지 않습니다.
- 체크 아이콘은 설치·로그인 확인, 느낌표는 로그인 필요, X는 실행 파일/버전 점검 필요, 회전 아이콘은 점검 중을 뜻합니다. 모델별 계정 권한·사용 한도는 실제 실행 결과로 확인합니다.
- 연결 다시 점검을 웹에서도 제공하고, 웹의 시작 시점에 고정되어 있던 상태를 현재 로그인 상태로 갱신합니다. 표시 중인 유휴 화면은 주기적으로 점검합니다.
- 원문과 결과의 헤더·도구 모음·파일 정보 공간을 맞추고 두 텍스트 필드의 높이를 동일하게 고정했습니다. 모바일에서 세로로 쌓여도 같은 높이를 사용합니다.
- 전체 진행률 옆에 경과 시간을 표시합니다. 변환 버튼부터 대기·처리 시간을 포함해 계산하며 완료·실패·취소 시 멈추고 새 작업에서 초기화합니다. 백그라운드 타이머 지연이 누적되지 않도록 실제 경과 시간으로 계산합니다.

모델 목록은 설치된 Codex 0.153.4의 bundled catalog와 Claude의 공식 모델·effort 문서를 확인해 구성했습니다. Codex는 GPT-6 Astra, GPT-5.6 Sol/Terra/Luna, GPT-5.5, GPT-5.2를, Claude는 Opus 5, Sonnet 5, Fable 5.1을 제공합니다. 모델 접근 권한을 확인한 목록이 아니라 선택 가능한 설정 목록입니다. 기본값은 기존 Sol/Opus와 medium을 유지합니다.

참고: [Claude Code 모델 설정](https://support.claude.com/en/articles/11940350-claude-code-model-configuration), [Claude effort](https://platform.claude.com/docs/en/build-with-claude/effort).

Windows 배포물은 `release/HumanizeKR-0.3.1-win-x64-self-signed.exe`입니다. 이전 0.3.0 EXE는 유지합니다. 스킬의 실행 모델은 기존처럼 호스트 세션이 선택하므로 이 앱 설정 메뉴와 별개입니다.

## 검증

단위·통합 테스트 200개, 웹 브라우저 테스트 20개를 통과했습니다. 요청별 모델·effort 전달, 잘못된 조합 거절, 문서 변환에서의 선택값 전달, 로그인 상태 재조회, 설정 저장·복원, 두 필드의 실제 크기, 초시계 시작·완료 후 정지·초기화를 검사했습니다. 웹·모바일 시각 스냅샷과 앱 화면을 확인했습니다.

최종 packaged Windows 앱 테스트 10개도 통과했습니다(총 자동 테스트 230개). 모델 설정 재실행 유지, 실제 CLI 인자, DOCX/PPTX 저장, 취소·종료 시 작업 정리를 포함합니다. 숨겨진 Windows 창의 화면 캡처 지연은 별도 시각 QA로 분리하고 기능 검증을 완료했습니다.

로그인된 실제 CLI로 GPT-6 Astra/low와 Claude Sonnet 5/low를 각각 호출해 구조화된 윤문 결과를 받았습니다. 모델별 가능한 모든 조합이나 계정의 전체 접근 권한을 시험한 것은 아닙니다. 기존 조건부 live/성능 테스트 3개는 건너뛰고 위 2개 실호출을 별도로 수행했습니다.
