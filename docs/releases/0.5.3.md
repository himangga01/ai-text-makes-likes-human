# 0.5.3 — 이 PC 전용 접속과 보안 강화

0.5.2 이후의 변경이다.

## 접속

- **포털은 이 PC에서만 열린다.**
  - 서버는 `127.0.0.1`에만 열리고, 같은 PC에서 온 연결만 받는다. `HOST`로 다른 주소에 열어도 이 검사는 그대로다.
  - 같은 와이파이의 다른 PC가 서버 IP 주소로 직접 접속하던 방식은 없앴다. 다른 기기는 외부 주소로 접속하고 비밀번호를 넣는다.
  - 시작할 때 와이파이 주소를 보여 주지 않고, 잘못된 주소 안내 화면에도 주소 목록이 없다.
  - Windows 방화벽을 여는 `scripts/allow-lan-firewall.ps1`을 없앴다. 예전에 연 규칙은 `scripts/remove-lan-firewall.ps1`로 지운다.
- **터널을 거쳐 온 요청은 언제나 외부 방문자로 본다.** 요청의 Host가 무엇이든 외부 주소와 비밀번호를 거친다.
- **로그인 시도는 비밀번호를 확인하기 전에 센다.** 비밀번호 확인은 한 번에 하나씩 하고, 기다리는 시도가 많으면 바로 거절한다. 시도 횟수 제한 값은 그대로다.
- **로그아웃하면 서버에서도 세션이 끝난다.**
  - 로그인한 세션을 `runtime/public-sessions.json`에 적어 두고, 목록에 없는 세션은 받지 않는다.
  - 이 버전으로 올리면 외부 주소에서 한 번 다시 로그인해야 한다.

## AI CLI 실행

- **Codex와 Claude는 모델 호출 말고는 아무것도 할 수 없게 실행한다.**
  - 두 CLI 모두 작업마다 프로젝트 밖에 새로 만든 빈 임시 폴더에서 시작한다. 프로젝트 지침·설정·git 정보를 읽지 않는다.
  - Codex는 셸·코드 실행·하위 에이전트·웹 검색·이미지 도구·훅·플러그인·스킬·메모리를 끄고 읽기 전용 샌드박스로 실행한다.
  - Claude는 제한 모드와 안전 모드에서 도구 없이 실행하며 CLAUDE.md·자동 메모리·스킬·훅·플러그인을 불러오지 않는다.
  - 모델 목록 조회도 같은 방식으로 빈 임시 폴더에서 한다. `runtime/model-probe`는 더 쓰지 않는다.
- **하위 프로세스에는 필요한 환경 변수만 넘긴다.** 서버, CLI, Python 단계가 모두 해당한다. 포털을 시작한 터미널이나 에이전트 세션의 토큰·소켓은 넘어가지 않는다.
- **원문에 없던 이메일 주소가 들어간 모델 응답은 불량 출력으로 처리한다.**

## 문서(DOCX·PPTX)

- **문서 크기와 구조에 상한을 둔다.**
  - 압축 해제 250 MiB, XML 전체 24 MiB, XML 노드 150만 개, 중첩 64단계, 추출 텍스트 10만 자, 모델에 보낼 구간 60개 등이다.
  - 넘으면 내용을 읽기 전에 `DOCUMENT_TOO_LARGE`와 이유를 바로 알려 준다. 포털·앱·스킬·MCP가 같다.
- **보관 시간은 늘어나지 않는다.** 올린 뒤 30분, 결과가 나온 뒤 다시 30분이다. 열어 보거나 내려받아도 늘지 않고, 만료·삭제 때 받는 중인 다운로드는 끊는다.

## MCP·스킬

- **MCP `humanize_file`의 `outputPath`는 원본 파일과 같은 폴더나 그 하위 폴더의 새 파일만 받는다.** 그 폴더는 이미 있어야 한다.
- **MCP 서버는 같은 PC의 포털에 연결한다.** 기본 주소는 `http://127.0.0.1:7882`다.
- **스킬 Gateway의 기본 작업 폴더는 사용자 전용 폴더다.** Windows는 `%LOCALAPPDATA%\humanize-kr-skills`, 그 밖에는 권한 0700의 사용자별 임시 폴더다. 엔진 코드 경로는 작업 파일(`job.json`)에서 읽지 않는다.

## 의존성

- 운영: body-parser 2.4.0, proxy-addr 2.0.8, qs 6.17.1.
- 개발·빌드: Electron 44.11.5, vitest 4.1.12, vite 8.3.8 등. electron-builder가 쓰는 minimatch는 `overrides`로 11.x를 쓴다.
- `npm audit` 결과는 전체와 운영 의존성 모두 0건이다.
- Windows 배포판에 넣는 Python은 3.14.10, Node는 24.22.3이다. 다음 Windows 빌드 전에는 `build-resources/python`을 지운다.
