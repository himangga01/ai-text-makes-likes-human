# T12 report: Korean-language resource tools for Super Sejong v2 — discovery and security audit

## Summary

- **No third-party MCP server or plugin should go into the product.** Every useful upstream is either an official API that is easy to call directly, or a data dump with a clear licence. Every wrapper I audited adds risk and gives nothing that a ~100–400-line product-owned client wouldn't.
- **Use directly in the product:**
  - Kiwi (`kiwipiepy==0.24.0`). It is already used by research, is clean, and makes no network calls at runtime.
  - The official NIKL dictionary dumps and Open APIs (표준국어대사전, 우리말샘, 한국어기초사전). The text is CC BY-SA 2.0 KR, commercial use is allowed, and attribution and share-alike are required.
- **Safe to try for v2 research (personal/agent use, pinned, with conditions):**
  - `ko-stdict-mcp`. It is AGPL, so research only.
  - `korea-scholarship-mcp` (KCI + OAK).
  - `rubatoyd/KCI_openAPI` and `rubatoyd/scienceON-mcp`, but only at specific post-fix commits.
  - `blazickjp/arxiv-mcp-server` 0.8.0.
- **REJECT:**
  - **Every spell-checker MCP that scrapes Naver, 부산대 or 나라인포테크.** One of them also spoofs `X-Forwarded-For` to dodge rate limits.
  - **koreandict-mcp-server.** It reads `~/.cursor/mcp.json` and the `.env` in the directory it is started from.
  - **lwsinclair/stdict.** It reads the Claude Desktop config.
  - **kisti-mcp.** Its licence is CC-BY-NC, and it logs API keys and tokens at INFO level.
  - **paper-search-mcp.** It ships a Sci-Hub download tool, turns TLS verification off, scrapes Google Scholar with rotating user agents, and lets the model choose where files are written.
- **Bareun** (바른, Baikal AI, first-party) is the only legitimate commercial Korean spell/grammar API with an MCP endpoint. Using it is a business and data-flow decision: user text is sent to a third party, and its privacy and retention terms were not verifiable. Its code itself is not a risk.
- **Discovery result:** no MCP exists for 모두의 말뭉치, 온라인가나다, 어문 규범, 한국학중앙연구원, RISS or DBpia. No Korean-language plugin exists in the local Claude plugin marketplace.

### Evidence levels and method
- **Code findings** come from reading the code. Every security finding was read in source (file:line given).
- **Terms findings** come from pages I opened (URLs given). Where I could not open a page, I say so.
- **Recommendations** are my own reasoning.
- **Rules followed:**
  - Nothing was installed or executed: no npm/pip/uvx/deno run/docker.
  - Code was fetched only by `git clone --depth 1` or curl of registry artifacts (npm `.tgz`, PyPI wheels, JSR files) into the scratch directory.
  - No MCP server was added to any configuration.
- **How the work was split:** two forked sub-agents did groups A (dictionaries) and B (Korean scholarly APIs). I did groups C (international paper search) and D (spell/NLP), Part A.4 (official APIs) and discovery. A third and fourth fork could not be started because of the concurrency limit.
- **Search coverage gap:** the session's WebSearch budget ran out midway, so later discovery used `gh search`, the official MCP registry API and WebFetch.
- **Corrected method error (OSV):** early OSV queries returned "0 vulns" because the request lacked `Content-Type: application/json`. All OSV numbers below come from re-runs with the header; group B used `querybatch` with the header from the start.
- **Over the shortlist limit:** I audited 14 candidates, more than the 10 asked for. Several were short audits whose verdict was clear early.

## Part B — Audit details

### Checks applied to every audited candidate
- Install-time hooks.
- Network destinations, telemetry and dynamic code.
- File-system scope and environment-variable handling.
- Prompt-injection exposure.
- Transport.
- Dependencies and OSV advisories.
- Published artifact compared with the git source.

### B1. dahlia/ko-stdict-mcp — SAFE WITH CONDITIONS (research only)
- **Network:** the only call is a POST to `https://stdict.korean.go.kr/common/download.do` with `link_key=1538740` (`src/config.ts:8-12`, `src/source/download.ts:59-70`). There is no telemetry.
  - `KO_STDICT_DOWNLOAD_URL` can redirect the download elsewhere. Leave it unset.
- **Files:** writes only under `~/.local/share/ko-stdict-mcp` or `--data-dir` (`config.ts:37-53`).
- **Code:** no eval, `Function` or `Deno.Command`. SQL is parameterised (`src/query/search.ts:44-71,140-150`). The zip is read in memory (`src/source/unpack.ts:8-35`).
- **Low-risk finding:** the filename from the server's Content-Disposition header is URL-decoded and joined without cleaning (`src/utils.ts:59-66`, `src/source/download.ts:78-96`). A malicious response could write outside the data directory. Mitigate with Deno `--allow-write` limited to the data directory.
- **Transport:** stdio only (`server.ts:134-140`). Results are structured dictionary JSON, not raw web content.
- **Supply chain:**
  - JSR 0.2.0 matches tag 0.2.0 (commit 168f902). The only differences are the import-specifier rewrites JSR makes when publishing.
  - Locked versions with no advisories: SDK 1.28.0, @zip.js/zip.js 2.8.23, zod 4.3.6.
  - Transitive hono (31 advisories) and others with advisories sit only on the HTTP-transport path, which this stdio server never imports.
- **Unverified:** the official dump normally needs a member login, while this server POSTs without a session. I did not call the endpoint, so I cannot say whether NIKL permits this.
- **Conditions:**
  - Pinned checkout: `git clone https://github.com/dahlia/ko-stdict-mcp && git -C ko-stdict-mcp checkout 168f902 && deno install --frozen`.
  - Run: `deno run --frozen --allow-net=stdict.korean.go.kr --allow-read=<DATA> --allow-write=<DATA> --allow-env=KO_STDICT_DATA_DIR,KO_STDICT_DOWNLOAD_URL,KO_STDICT_JSON_LINK_KEY,XDG_DATA_HOME,HOME main.ts --data-dir <DATA>`.
  - Never use the README's `deno run -A jsr:…` (`README.md:55-66`), which grants every permission to an unpinned version.
  - AGPL: do not embed it in the product or expose it as a network service.

### B2. tenacl/koreandict-mcp-server — REJECT
- **Reads another program's configuration in the home directory:** `~/.cursor/mcp.json` (`src/config.ts:26-31`; published `dist/config.js:22-26`).
- **Reads files from wherever it is started:** `mcp.json` in the current directory (`src/config.ts:42-43`), and `.env` via dotenv (`src/config.ts:1,8`). Started from the product repo, it would load the product's `.env`.
- **Repo hygiene:** commits `node_modules/` (139 packages), a `.tgz` and a `.env`. The `.env` is byte-identical to `.env.example`, so it is a placeholder; the content was not displayed.
- **Vulnerable locked dependencies:** axios 1.8.4 (32 OSV advisories) and @modelcontextprotocol/sdk 1.8.0 (GHSA-8r9q-7v3j-jr4g ReDoS; GHSA-w48q-cv73-mx4w DNS rebinding).
- **Maintenance:** one commit, by a placeholder identity.
- **What checked out clean:** no install hooks, and the npm tarball matches git `dist/`.

### B3. spellcheck-ko/korean-dict-nikl — SAFE WITH CONDITIONS (data only)
- About 3 GB of XML at HEAD 42c0d01: stdict dump 20260605, 우리말샘 20260602, krdict 20260619.
- The only code is three 27-line `update.py` scripts that unpack a local zip. They make no network calls and have no path traversal (`stdict/update.py:13-18`). Do not run them.
- No LICENSE file. The README states CC BY-SA 2.0 KR and warns that cited usage examples and multimedia are not open.
- **Conditions:**

## Part C — Recommendations

### For v2 research (agent-side, owner approval needed for each)
1. **Dictionaries:**
   - Prefer the official NIKL dump. Use the korean-dict-nikl XML (sparse, pinned) only until the owner downloads the dump himself.
   - Optionally use ko-stdict-mcp under the Deno permission sandbox above.
2. **Korean papers (《한국어학》 etc. via KCI):** korea-scholarship-mcp pinned to 8ed87e3. Use rubatoyd's KCI and ScienceON servers only at the stated commits.
3. **International papers:** arxiv-mcp-server 0.8.0 (stdio, sandboxed storage). For Semantic Scholar, OpenAlex and ACL Anthology, use direct REST or the `semanticscholar`, `pyalex` and `acl-anthology` libraries instead of any MCP.
4. **Spell-check comparison:** use only Bareun, with a research key and only on public text such as already-published blog posts, until its data terms are verified. Never use the Naver, Daum or PNU scrapers, even for research.
5. **For all MCP use:**
   - stdio only, project scope (not user scope), pinned versions.
   - Launch from an empty working directory with no `.env`.
   - Deny or approval-gate write tools.
   - Treat all returned text as untrusted data.

### For the product — build our own
1. **`nikl_lexicon` importer:** official stdict, 우리말샘 and krdict dumps loaded into SQLite with source version and date.
   - Store attribution "국립국어원 표준국어대사전/우리말샘/한국어기초사전, CC BY-SA 2.0 KR".
   - Drop cited usage examples (출전 있는 용례) and multimedia.
   - Keep any derived lexicon under CC BY-SA, and document whether it counts as an adaptation, consistent with report J (`docs/research/super-sejong/J-lexicon-collocations.md:55`).
   - Optionally add a thin Open API client (key from an environment variable only, scrubbed from errors and logs; krdict allows 50,000 requests a day).
2. **Kiwi** (`kiwipiepy==0.24.0`, hash-pinned, binary only) as the morphology, sentence-splitting and spacing backbone. Do not add kss.
3. **어문 규범 Open API** client for checking how loanwords and romanised forms are written.
4. **No external spell checker in the request path.** If one is wanted later, Bareun is the only lawful commercial option. It needs a contract plus privacy and retention terms, and it would act as an advisory verifier, never as the rewriter. Naver, Daum and PNU/나라인포테크 web endpoints are not acceptable.
5. **Research-only KCI and arXiv clients** (about 150 lines each: defusedxml, key scrubbing, rate limits). They need no product integration.
