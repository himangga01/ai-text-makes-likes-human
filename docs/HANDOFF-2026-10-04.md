## Implemented behavior in the working tree

- [TypeScript style diagnosis](../src/engine/super-sejong.ts) emits bounded source offsets for two public-prose constructions. [Prompt integration](../src/engine/prompt-builder.ts) treats them as review candidates, not automatic corrections. Quoted/code/structural regions are excluded.
- [Python semantic guards](../engine_runtime/super_sejong.py) look for selected negation, modality, obligation, overt role, and lexical reversals. They feed [TXT/MD validation](../engine_runtime/workflow.py) and [Office validation](../engine_runtime/documents/model.py); [quantity normalization](../engine_runtime/quantities.py) supplies shared numeral/unit checks. Failed edits can retry or preserve source. These surface heuristics do not prove semantic equivalence.
- The benchmark-triggered correction recognizes `아닙니다` and attributive `아닌` as negative surfaces, and treats attached `안됩니다` as negative so a spacing-only change to `안 됩니다` is not mistaken for a polarity flip. This is **not** a global spelling replacement. Regression cases are in [content-fidelity tests](../tests/skills/test_content_fidelity.py).
- Other reviewed changes cover runner tool/workspace isolation and bounded output, private Host validation, bounded Office XML loading, fixed public errors, desktop import/save-target state, accepted Office character counts, and the `/api/status` supervisor integration. See the review report and code analysis for file-level details.

## Measured outcomes and interpretation

The live comparison used 20 bodies totaling 55,683 characters. It sampled 20 IDs with a fixed seed from **28 publicly prologue-visible posts**, while the blog displayed 456 posts overall. It is not a uniform sample of all 456 or a multi-writer corpus. Both arms used the same prepared body, `gpt-5.6-sol` at `medium`, automatic routing, one body chunk, sequential execution, and alternating arm order. “Existing engine” means the **current service with only Super Sejong style findings and four new semantic checks disabled**, not an older release binary. Model calls were unseeded and stochastic.

| Across 20 posts | Existing-engine ablation | Super Sejong |
| --- | ---: | ---: |
| Final output changed | 17 | 17 |
| Median wall time | 69.4 s | 76.7 s |
| Model calls / retries | 29 / 9 | 33 / 13 |
| Chunk rollbacks | 3 | 3 |
| Final outputs flagged by the full gate on replay | 4 | 0 |

The four flags are **not** four independently confirmed meaning errors. Some reviewed spans were plausible contrastive paraphrases or sentence-boundary changes. Style findings occurred in only one input. No blinded Korean-reader judgments, semantic labels, or dependable naturalness/speed advantage were established. In a targeted positive-only probe, the initial Super Sejong gate aborted 14/20 deliberately meaning-flipped copies and the corrected gate aborted 20/20; this is not a general recall, specificity, or accuracy estimate. See the benchmark report for all 20 rows and the interpretation limits.

## What is portable, and what is not

The repository contains **post IDs, source URLs, titles, lengths, full source SHA-256 hashes, aggregate/per-post metrics, and probe outcome codes**. It does not contain the blogger's full article bodies or the 40 generated outputs. Those and the one-off benchmark/analyzer scripts were kept under `/tmp` during the experiment and may disappear or be unavailable in a new Codex environment. The MD report describes the extraction, sampling, arms, and measurements; exact output-level adjudication cannot be resumed from repository files alone. Re-fetching public posts and rerunning the live model can produce different outputs and costs; compare hashes and record a new run rather than treating it as the original. No authentication material or model output text should be copied into this handoff.

The working tree itself is the source of truth until a separately authorized transfer or commit. `git diff` alone omits untracked Super Sejong source and research/report files. Preserve those files when moving to another environment. A checkout containing only `c792440` cannot be used to continue this implementation without transferring the working-tree changes.
